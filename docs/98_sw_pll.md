# 软件锁相环

Android SurfaceFlinger 基于 hw-vsync 校准 app-vsync，使用软件锁相环（phase-locked-loop）。
不仅需要校准，还要精确控制相位。

wheel 是多核系统，每个 CPU 都有自己的时钟，这些时钟的中断也应该保持 2π/N 的相位差，较量避免两个 CPU 同时执行时钟中断。
可以使用 PIT、HPET 作为参考信号，使用 PLL 校准每个 Local APIC Timer。

## 锁相环

PLL 是一个闭环控制系统，让输出信号的频率、相位精确跟随参考信号。
PLL 不断检查输出信号与参考信号的误差，根据这个误差反馈修正参考信号，直到收敛。

如何计算误差？如何修改输出信号？

鉴相器（PD），计算反馈的输出信号和参考信号之间的相位差，也可以用异或、乘法。
鉴相器是一种专用硬件，输出正比于相位差的电压或电流。

环路滤波器（LF），对鉴相器的输出进行平滑滤波，去除抖动。
滤波后的输出就是控制信号。

压控振荡器（VCO），这是一种可调频率的晶振源，输入就是 LF 产生的控制信号。
输出频率 `f = k*x + b`，其中 x 就是控制信号。控制信号为零不表示输出频率为零。
