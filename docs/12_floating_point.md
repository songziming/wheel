# 浮点数支持

现状：能加载 elf 并运行，尚未支持浮点数。执行浮点指令会产生 #UD。

浮点相关指令集有三个：
- x87 fpu
- sse
- avx

wait/fwait 指令，作用是检查当前有无浮点异常

### lazy-fpu-switching

并不是每个任务都使用了浮点单元。任务切换的时候，不需要每次都保存/恢复浮点寄存器。
我们需要实现 lazy-fpu-switching，只有另一个任务需要使用浮点时，才把当前的寄存器保存下来
cr0.TS 就可以实现此功能。

cr0.EM 如果置位，执行sse指令会产生 #NM。OS 应该保持 EM=0
如果 cr0.TS=1 && cr0.MP=1，则执行任何浮点指令都会触发 #NM。这可以用来检测 lazy-fpu-switching。
如果 cr0.TS=1 && cr0.MP=0，执行浮点指令不会触发 #NM，需要执行一个 wait/fwait 指令才会产生 #NM，不满足需求。

我们切换任务时，置位 cr0.TS，这样新的任务执行浮点操作时，我们可以通过 #NM 捕获异常，然后保存前一个任务的状态。

### 放弃 lazy-fpu-switching

有两个问题：
- 任务退出时，这个任务的浮点状态仍留在某些 CPU 上，下次遇到 #NM 会发生 use-after-free
- 任务迁移到不同的 CPU，浮点状态仍处于前一个 CPU，无法自动迁移

方案：弃用 lazy-fpu-switching，现代 CPU 保存浮点寄存器足够快

### 浮点支持的内容

浮点数包括自己的指令和寄存器。
只要 CR0、CR4 开启相关指令集，就可以使用浮点指令。
任务切换时，使用 fxsave/fxrstor 保存恢复浮点状态。
